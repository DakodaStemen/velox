## Regular expression search engine

`vendor/boostregex/`: the regex integration for Scintilla.

- `BoostRegExSearch.cxx`: Copyright (c) since 2009 Simon Steele; (c) 2012 Dave Brotherstone;
  (c) 2013 Francois-R. Boyer; (c) 2019 Don Ho.
- `UTF8DocumentIterator.*`, `AnsiDocumentIterator.h`: Copyright (C) 2021 Don Ho and contributors
  (see file headers). GNU General Public License, version 3 or later.

Modified for Velox: `UTF8DocumentIterator.cxx` and `BoostRegExSearch.cxx` use whole UTF-32 code
points where `wchar_t` is 32 bits, so characters outside the Basic Multilingual Plane (such as
emoji) match as single characters.
