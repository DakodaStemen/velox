# Security policy

## Supported versions

Security fixes are made for the latest release only.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use the repository's private
vulnerability reporting ("Report a vulnerability" on the Security tab) instead. Include the affected
version, a description of the issue and steps or a sample file to reproduce it.

You can expect an acknowledgement within a week. We will keep you informed while we work on a fix
and credit you in the release notes unless you prefer otherwise.

Velox opens untrusted files. Crashes or hangs caused by crafted files, problems in the bundled
regular expression engine, and anything that could lead to data loss on save are all in scope.
